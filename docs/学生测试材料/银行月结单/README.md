# 银行月结单 / 银行流水证明测试材料

用途：材料识别、OCR、字段抽取和银行流水/账户月结单版式测试。

## 当前材料

- `sample-ImpactBank-dummy-statement.pdf`
  - 公开样例 PDF，包含账户摘要、日期、交易明细、存取款和余额字段。
  - 来源：https://www.impact-bank.com/user/file/dummy_statement.pdf

- `sample-YourBank-bank-statement-example.pdf`
  - 公开仿真 Bank Statement Example，包含多笔交易流水、入账、出账和余额。
  - 来源：https://the-bac.edu/Documents/Departments/Admissions%20Financial%20Aid/Admitted%20Students/International/Bank%20Statement%20Example%20Final.pdf

- `sample-HSBC-HK-credit-card-statement-page-1-redacted.png`
- `sample-HSBC-HK-credit-card-statement-page-2-redacted.png`

  - 公开博客中的 HSBC HK 信用卡月结单红acted图片，包含香港银行月结单版式、账户/账单区域和交易表区域。
  - 来源：https://bankstatementconverter.com/blog/posts/2021-09-22-hsbc-credit-card-review/

## 使用边界

- 本目录只保存公开样例、仿真样例或已公开红acted图片。
- 不保存网上泄露、未授权公开、含真实个人账户、交易、余额、地址等敏感资料的月结单。
- 这些材料用于测试识别流程，不代表入境处或银行官方指定模板。
