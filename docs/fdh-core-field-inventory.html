范围：ID 988A、ID 988B、ID 407。目标是在识别结果页和核验结果页展示每个字段的字段名、识别值、局部截图、归一结果、置信度、来源材料、页码/章节，并标出需要跨材料一致性核验的字段。

跨材料一致性核验汇总

这些字段应在识别结果页合并展示多个来源，在核验结果页显示建议归一值、来源列表、冲突值、局部截图和置信度。

标准字段 来源材料 建议采用值规则 结果状态规则 是否阻断
case.application_type
申请类别		ID 988A Application Type；首页用户选择以首页选择为期望值，ID 988A 必须匹配。不一致为 fail；多选为 review 或 fail。是
document.footer_id
模板页尾/页数		ID 988A、ID 988B、ID 407以页尾 ID 和版本识别材料类型；页面数按官方模板。低置信、缺页、错模板进入材料层 fail/review。材料 1-3 阻断
helper.name.full_en
傭工英文全名		ID 988A surname/given names；ID 407 Name of Helper；旅行证件姓名组合 ID 988A given + surname；高置信证件/合约值可辅助建议。明显不一致为 fail；轻微 OCR 差异为 review；纠偏后仍 review。是
helper.travel_doc.number
傭工旅行证件号码		ID 988A Travel document no.；ID 407 helper document no.；旅行证件副本优先证件副本高置信值；格式差异可归一。明显不一致为 fail；低置信/疑似 OCR 差异为 review。是
helper.date_of_birth
傭工出生日期		ID 988A；旅行证件副本；如 ID 407 有 DOB 则纳入归一为 ISO 日期后比较。不一致为 review/fail，取决于置信度和差异严重性。是
helper.nationality
傭工国籍		ID 988A；旅行证件副本；如 ID 407 有国籍则纳入国家名/国籍词归一，例如 Indonesia -> Indonesian。归一后一致为 pass；低置信或不一致为 review。是
employer.name.full_en
雇主姓名		ID 988B；ID 407；雇主身份证明ID 407 如中文名，则优先与 ID 988B 中文名比较；否则比较英文名。明显不一致为 fail；单来源或低置信为 review。是
employer.id_doc.number
雇主证件号		ID 988B；ID 407；雇主身份证明归一去空格、大小写、常见 OCR 噪声。不一致为 review/fail；单来源展示但不显示未识别。建议阻断/待复核
employer.address.residential
雇主/雇佣地址		ID 988B；ID 407；住址证明地址标准化后做弱一致；允许格式和换行差异。明显不同地址为 review；不自动 pass。待复核
