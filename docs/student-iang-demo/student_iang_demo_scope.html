场景 官方业务 核心判断 主要审核材料 Demo 优先级
学生首次来港就读 Entry for Study 是否被合资格课程/学校取录；是否有本地保证人；是否有足够资金；未成年监护安排。 ID 995A、ID 995B、照片、旅行证件/港澳通行证或身份证、取录信、HKID 如有、资金证明、住宿证明、未成年监护同意书。 高
学生延期逗留 Extension of Stay for Study 是否仍在获批课程就读；申请时间是否在到期前窗口；当前逗留身份是否连续。 旅行证件、最新 arrival stamp / landing slip / e-Visa、HKID、院校在读/继续修读证明、现有学生签证/进入许可。 中
学生实习/校内兼职/暑期工作资格核验 Student Conditions of Stay / NOL 课程层级、学习时长、实习是否课程相关并由院校安排/认可；NOL 条件是否匹配。 No Objection Letter、院校实习证明、课程证明、雇主/岗位资料、学生身份材料。 中
终止修读通知 Notification of Termination of Studies 院校是否在学生终止课程后通知入境处；学生身份与课程信息是否可定位。 ID 977、学生姓名、出生日期、HKID、院校名称、终止日期、授权人士签署和院校印章。 低
IANG 应届毕业生首次申请 Non-local recent graduates / GBA campus recent graduates 毕业日期距申请是否不超过 6 个月；学历是否本科或以上/合资格 QF Level 5+；应届通常不要求已有聘用。 照片、旅行证件/港澳通行证、HKID 如有、成绩单/毕业证/院校证明信、内地赴港工作同意书如适用、付款证明、landing slip/e-Visa 如在港。 最高
IANG 非应届毕业生首次/回港申请 Non-local non-recent graduates / GBA campus non-recent graduates 毕业超过 6 个月；必须已有聘用；岗位通常由学位持有人担任，薪酬福利达市场水平。 IANG 个人材料、学历证明、雇佣合约/聘书、公司商业登记证、财务证明、新公司商业计划、内地赴港工作同意书如适用。 高
IANG 延期逗留及顶尖人才延期 Extension of Stay under IANG 是否已有聘用或在港经营业务；普通延期通常 3-3 年；顶尖人才需 IANG 留港不少于 2 年且上一课税年度薪俸税应评税入息不少于 HKD 2,000,000。 旅行证件、HKID、现有 e-Visa/landing slip、雇主证明信、雇佣材料、业务证明、税务评税通知书/税务证明。 中
IANG / 学生受养人 Dependants 关系是否真实；受养人是否无不良记录；保证人/主申请人是否有能力维持生活和住宿。 受养人照片、旅行证件、关系证明、出生/结婚证明、主申请人身份及逗留证明、澳门/台湾/海外居留证明如适用。 中
职专毕业生留港计划 VPAS 是否就读合资格 VTC 指定课程；毕业后留港寻找或从事相关技术行业工作。 VPAS 指南所列学历、课程、身份、聘用/行业相关证明。可作为 Phase 1 拓展场景。 候选

二、IANG 首批 Demo 材料包

材料 识别重点 核验规则 典型异常
港澳通行证 / EEP 姓名、证件号码、出生日期、签发地、有效期、签注类别。 与申请人姓名、HKID、landing slip/e-Visa 交叉一致；证件在申请和入境时有效。 证件过期、签注缺失、姓名拼音/中文名不一致、页面拍摄反光。
毕业证明 / Certifying letter / 成绩单 / 毕业证 院校、课程、学位/资历、毕业日期、全日制、本地评审/大湾区校园线索。 应届按毕业证日期或院校证明判断 6 个月窗口；学历须本科或以上/符合官方资历定义。 仅有 completion letter 但无毕业日期、院校非授权、课程层级不足、姓名与证件不一致。
HKID 英文姓名、中文姓名、HKID 号码、出生日期、签发日期。 与申请表、旅行证件、landing slip 交叉一致；如无 HKID 则按官方“if any”处理。 HKID 遮挡、号码校验位不清、旧版/新版版式混杂。
付款证明截图 付款渠道、金额、交易时间、申请类别、交易参考号。 IANG 属指定计划，通常涉及申请费和签证签发费；付款状态应与申请阶段一致。 截图缺交易号、只显示待支付、金额/币种不清、重复上传。
小白条 / landing slip 入境日期、获准逗留至、身份/条件、旅行证件号码。 若申请人当前在港，需与最新逗留期限和身份连续性匹配；延期申请不得逾期。 拍摄模糊、只上传旧 landing slip、与 e-Visa 不一致。
《内地的居民赴港工作同意书》 申请人姓名、身份证号、工作单位/主管机关、同意赴港工作表述、签章日期。 内地居民适用；需核对签章、日期和申请人身份；作为 ID 991 附件材料处理。 无单位盖章、日期早于合理范围、姓名或身份证号与证件不一致。
雇佣合约 / 聘书 雇主、岗位、薪酬福利、雇佣期、签署日期。 非应届 IANG 或 IANG 延期重点材料；岗位应通常由学位持有人担任，薪酬达市场水平。 无薪酬、无雇佣期、公司名与商业登记不一致。
公司材料 商业登记证、财务证明、新公司商业计划。 非应届/部分延期申请需要；若公司符合官方豁免条件可不提交部分公司材料。 BR 过期、财务文件非最近年度、新公司无商业计划。

三、规则优先的识别链路建议

  1. 先识别官方表格/材料类型：用页眉、页脚表格号、标题、固定字段版式判断，例如 ID 995A、ID 995B、ID 990A、ID 977、ID(C/E) 996、ID(E) 991。
  2. 再进入场景模板：IANG 应届、IANG 非应届、学生首次、学生延期、受养人、终止修读通知分别使用不同必交/条件应交清单。
  3. 最后做跨文件校验：姓名、证件号、HKID、出生日期、毕业日期、逗留期限、雇主名称、薪酬、付款记录跨文件对齐。
  4. 低置信度不自动通过：证件反光、landing slip 模糊、毕业证明缺毕业日期、付款截图缺交易号，均进入待复核。

四、Demo 页面建议

页面/Tab 展示内容 对客户的价值
材料上传 预置 IANG 应届、IANG 非应届、学生首次三个案例；支持材料 1-N 上传。 体现 Phase 1 Student/IANG 与现有 FDH 流程一致。
文档分类 材料类型、官方表格号/证件类型、页数、置信度、局部截图。 证明“规则优先 + 版式识别”不是整页 LLM 猜测。
字段提取 按申请人、身份、学历、逗留、雇佣、付款分组字段。 方便复用现有标准化字段表组件。
跨文件核验 姓名/HKID/证件号/毕业日期/逗留期限/雇主/薪酬的来源矩阵。 贴合 RFI 的 data verification 和 confidence indicators。
Minutes 草稿 按官方材料顺序输出结论：通过、未识别、必填未填写、待复核。 延续 FDH demo 的最终审核结论能力。
